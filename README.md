# Братская керамика — сайт и админ-панель

Текущая версия из папки «крутая заказчица». Включает основной сайт, админку, сервер сохранения, цены, расписание и используемые фотографии.

## Запуск

Нужен Node.js 22+. Установка зависимостей не требуется.

```sh
npm start
```

Сайт: http://127.0.0.1:4173/

Админка: http://127.0.0.1:4173/admin

При первом запуске автоматически создаётся случайный пароль в `data/admin-password.txt`. Файл не публикуется в Git. Можно задать пароль секретом окружения `ADMIN_PASSWORD`.

Исходное публичное содержимое хранится в `data/default.json`. Рабочие изменения — в `data/content.json`, фотографии — в `public/uploads`; они создаются при запуске. Начальные фото копируются из `public/seed-uploads` без перезаписи уже существующих файлов.

## Размещение

Для работающей админки нужен Node.js-хостинг с постоянным диском или Docker. GitHub Pages не запускает сервер и не сохраняет изменения этой админки.

```sh
docker build -t bratsk-ceramics .
docker run -d -p 8080:8080 -v bratsk-data:/storage bratsk-ceramics
```

Для публикации настройте HTTPS-прокси. Контейнер использует `COOKIE_SECURE=1`; для локальной проверки по HTTP можно передать `-e COOKIE_SECURE=0`.

Переменные: `HOST`, `PORT`, `DATA_DIR`, `UPLOADS_DIR`, `ADMIN_PASSWORD`, `COOKIE_SECURE`. Папки данных и фотографий должны быть на постоянном диске.

## Проверки

```sh
npm run check
npm test
```

В репозиторий не входят пароли, заявки посетителей, резервные копии, локальные журналы и программы туннеля. Форма заявок по умолчанию отключена; запись через Telegram-бота. Перед коммерческой публикацией подтвердите сведения об исполнителе и права на фотографии, документы по персональным данным и условия оказания услуг.
